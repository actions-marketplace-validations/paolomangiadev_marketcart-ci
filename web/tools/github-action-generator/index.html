Setup for hosted mode

  1. Add the store's verification tag: get it from the checker (free) or GET /v1/domain-token?host=<your-store> with your license, and paste it into layout/theme.liquid inside <head>.
  2. Repository › Settings › Secrets and variables › Actions › New repository secret: MARKETCART_LICENSE (your key) and, for password-protected development stores only, MARKETCART_STOREFRONT_PASSWORD.
  3. Commit the workflow and the cases file. Use real product URLs and numeric variant IDs; "checks": {"total": true} makes a missing total inconclusive instead of silently skipped.

What the exit codes mean

0 every case PASS · 1 at least one REGRESSION (stored cart and visible cart disagree) · 2 only inconclusive results (UNSUPPORTED theme or market, BLOCKED by rate limiting or a password wall, ERROR) · 3 license or API error. Hosted runs bill only PASS and REGRESSION.

Theme and surface support

Dawn family and Horizon 4.4. A theme with a cart drawer is tested on the drawer; otherwise on /cart. Live-verified so far: Dawn 16.1.1 on the cart page; Dawn drawer and Horizon are verified on version-pinned synthetic markup only. Other themes return UNSUPPORTED.

Try it: run the free demo (sample store, no account), check one case on your own store for free (needs a verification tag in your theme), or use the open-source CLI and GitHub Action locally. Hosted runs: EUR 19 for 100 completed cases (30 days from activation, no subscription).
